# Semantic Book Recommender

A machine learning project for book recommendations using semantic analysis and vector search.

## Project Structure

- `gradio-dashboard.py` - Interactive dashboard for book recommendations
- `data-exploration.ipynb` - Data analysis and exploration
- `sentiment-analysis.ipynb` - Sentiment analysis implementation
- `text-classification.ipynb` - Text classification models
- `vector-search.ipynb` - Vector search implementation
- `books_cleaned.csv` - Cleaned book dataset
- `books_with_categories.csv` - Books with category classifications
- `books_with_emotions.csv` - Books with emotion analysis

## Setup

1. Install required dependencies
2. Configure environment variables in `.env`
3. Run the Gradio dashboard: `python gradio-dashboard.py`

## Features

- Semantic book search
- Emotion-based recommendations
- Interactive web interface
- Data visualization and analysis
